# MVP 14-5단계: Dify 흐름 재구성 (2026-10-17)

사람 확인은 한 곳: 진단을 보고 고를 개수를 확정한다. 확정하면 바로 선별·검수·학습 키트를 만든다. 학습은 하지 않는다.

## 흐름
```
시작 ─ 학습 결과 질문? ─ 예 ─ judge_results(최근 판정) ─ 판정 정리 ─ 답변
                      └ 아니오 ─ 질문 영어 변환 ─ 근거 검색 ─ 근거 정리(예산 읽기, 이번 차례 시각)
                                 ─ 에이전트(Gemma, 실패 시 Qwen): suggest_datasets / analyze_data / recommend_budget
                                 ─ pending_analysis ─ 진단 정리 ─ 개수 확인 필요?
                                     ├ 아니오 (질문 답, 데이터 제안) ─ 답변
                                     └ 예 ─ [사람] 개수 확인 카드 (진단·추천·근거, 개수 입력칸에 기본값)
                                            ├ 취소 ─ 기록 ─ 답변
                                            └ 이 개수로 고르기 ─ 기록 ─ select_demos ─ review_selection ─ 검수 판정
                                                 ├ revise ─ 답변 (문제 목록)
                                                 └ pass ─ build_kit ─ 키트·근거 정리 ─ 최종 보고(Gemma) ─ 답변
```
- 에이전트는 선별하지 않는다 (분석, 데이터 제안, 추천 개수만). 개수는 사람이 확정하고 흐름이 고른다
- `pending_analysis`: 이번 차례(근거 정리 노드가 기록한 시각) 이후의 분석 중 아직 고르지 않은 것만 본다. 다른 질문을 해도 이전 분석으로 개수를 다시 묻지 않는다
- 개수 확인 카드: Dify 사람 입력 노드의 입력칸(`{{#$output.budget#}}`, paragraph)에 기본값을 변수로 넣는다. 요청 문장에 개수가 있으면 그 수, 없으면 근거표의 추천 개수(Can 135, Square 150), 근거가 없으면 150
- 카드에 보이는 것: 데이터와 선별 후보 수, 위치 편중(부족한 칸 표), 거의 같은 시범 쌍 수, 추천 개수와 이유, 기본 개수가 실험으로 확인된 개수인지
- 결과 답변: 사람 확정 개수, 보고, 학습 키트 내려받기 링크(데이터·노트북 2종·설정·사용법), 근거 표(이 방법으로 고른 학습 실험의 묶음별 성공률과 판정), 수집 계획
- "학습 결과 보여줘": 사용자가 웹에 올린 결과의 최근 판정 (선별 효과 판정 또는 결과 확인)

## 도구 서버·중계 서버 변경
- `pending_analysis` 도구 추가
- `build_kit` 결과의 키 이름 `files` → `kit_files`, `data` → `data_file`: Dify 도구 노드가 `files`를 첨부 파일 출력으로 다뤄 노드가 실패했다
- 키트의 예상 시간을 실측으로: Can 묶음 하나 약 40분 (예산 60 2차 실험, 학습 + 평가 130회). 다른 데이터는 "측정 안 됨"
- 중계 서버 `/api/approve`가 사람 확인 카드의 입력값(`inputs`, 예: 고를 개수)과 버튼 이름을 그대로 Dify에 넘긴다

## 실제 대화로 확인 (게시 후, 중계 서버 API)
- "can 데이터로 학습할 시범 골라줘" → 카드: 부족한 칸 4개, 거의 같은 시범 0쌍(가장 가까운 2.6cm), 추천 135개(하락 기준 확인), 기본값 135
- [이 개수로 고르기] → 선별 135 → 검수 pass → 학습 키트 → 보고. 근거 표 Can 135: 선별 88% / 무작위 82% / 전체 75%
- "캔을 집어서 통에 옮기는 걸 학습시키고 싶어" → 데이터 제안(can_mh 먼저, 지원 범위 표시), 카드 없음
- "학습 결과 보여줘" → 올린 결과 없음 안내
