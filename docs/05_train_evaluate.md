# 5단계: Can 학습·평가 (2026-10-11 ~ 10-12)

## 무엇을 만들었나
- 도구 **train_evaluate** (`curation_tools/train_eval.py`, `server.py`)
  - `prepare`: 검수 pass를 받은 선별 결과로 학습 계획(`plan/plan.json`, 코랩에 붙여 넣을 한 줄 `plan_b64.txt`)을 만든다. 묶음 5개, 같은 설정, 같은 묶음·설정이면 같은 지문(fingerprint)
  - `collect`: 코랩 결과를 읽어 묶음별 성공률 비교표와 1주차 성공 기준 판정을 돌려준다. 판정은 코드가 한다 (LLM 아님). 같은 지문의 결과가 저장소에 있으면 다시 학습하지 않고 재사용한다
- 비교 기준선 **조건별 균등 무작위**(stratified_random) 추가: 칸별 개수는 선별과 같게, 칸 안에서는 무작위. 선별 효과를 "칸별 배분"과 "품질 점수"로 나눠 보기 위한 것
- 코랩 노트북 `colab/01_train_eval.ipynb`: 묶음별 필터 키 → robomimic 학습 → MuJoCo 롤아웃 평가. 평가 시드를 고정해 모든 묶음이 같은 50개 초기 상태에서 평가받는다
- 결과: `results/can_mh_c15466d53a01cedb_seed1.json` (시범 번호 없음, 성공률만)

## 학습 설정 (파일럿으로 확정)
train과 random_150 두 묶음만 BC와 BC-RNN으로 400 epoch까지 학습해 100 epoch마다 10회씩 평가했다.

| epoch | BC train | BC random | BC-RNN train | BC-RNN random |
|---|---|---|---|---|
| 200 | 3/10 | 3/10 | 7/10 | 3/10 |
| 400 | 2/10 | 1/10 | 10/10 | 8/10 |

BC는 전체 데이터로도 바닥이라 비교가 안 된다. BC-RNN(robomimic 논문의 low_dim 설정), 400 epoch, 최종 롤아웃 50회로 정했다. 200 epoch 시점 차이가 커서 학습 속도 비교용 중간 평가(30회)를 함께 둔다. 설정은 도구 인자로 받지 않아 LLM이 바꿀 수 없다.

## 본 실험 결과 (시드 1, 예비 결과)
지문 c15466d53a01cedb, 코랩 T4, 묶음당 학습 약 10분 + 평가 약 12분.

| 묶음 | 시범 수 | 400 epoch | 95% 신뢰구간 | 200 epoch |
|---|---|---|---|---|
| 선별 (curated_150) | 150 | 47/50 (94%) | 84~98% | 22/30 (73%) |
| 무작위 (random_150) | 150 | 40/50 (80%) | 67~89% | 9/30 (30%) |
| 조건별 균등 무작위 | 150 | 44/50 (88%) | 76~94% | 19/30 (63%) |
| 프레임 맞춘 무작위 | 104 | 39/50 (78%) | 65~87% | 9/30 (30%) |
| 전체 (train) | 270 | 48/50 (96%) | 87~99% | 21/30 (70%) |

| 판정 | 차이 | 95% 신뢰구간 | 결과 |
|---|---|---|---|
| 선별 - 무작위 (1주차: +5%p 이상) | +14%p | +1 ~ +27 | 차이 있음 |
| 전체 - 선별 (1주차: 하락 5%p 이내) | 2%p | -7 ~ +11 | 구분 불가 (기준 확정은 못 함) |
| 200 epoch 선별 - 무작위 | +43%p | +21 ~ +66 | 차이 있음 |
| 선별 - 프레임 맞춘 무작위 | +16%p | +3 ~ +29 | 차이 있음 |
| 조건별 균등 - 무작위 (칸별 배분 효과) | +8%p | -6 ~ +22 | 구분 불가 |
| 선별 - 조건별 균등 (품질 점수 효과) | +6%p | -5 ~ +17 | 구분 불가 |

해석
- 신뢰구간은 롤아웃 50회의 흔들림만 반영한다. 학습 시드에 따른 흔들림은 빠져 있어 "예비 결과"로 표시한다. 선별 - 무작위의 하한이 +1%p로 아슬아슬해서 시드 2, 3을 추가로 돌린다 (다음 작업)
- 학습 속도 차이(200 epoch +43%p)가 가장 뚜렷하다
- 데이터 55%로 전체와 비슷한 성능이지만, 롤아웃 50회로는 "5%p 이내"를 확정할 수 없다

## 코랩에서 겪은 문제
- 실행 중에 페이지를 새로고침하면, 바쁜 커널이 응답하지 않아 "연결 중"에 멈춘다. 커널은 계속 돌지만 화면 출력이 사라진다. 실행 중에는 새로고침하지 않는다
- 새로고침 후 이 브라우저에서 셀 출력이 표시되지 않아, 결과를 파일(`/content/results_main.json`)로 저장하고 변수 패널에서 읽어 옮겼다. 다음부터는 묶음마다 결과를 파일에 바로 쓴다
- 무료 코랩 GPU 한도: 하루 4시간 남짓 쓰면 "최대 1시간 지속 가능"으로 줄어든다. 긴 실험은 다른 GPU(Kaggle 등)를 검토한다
