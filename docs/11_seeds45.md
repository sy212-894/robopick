# 한계 1: 학습 시드 4·5 추가 (2026-10-13)

한계 목록과 공통 규칙은 `docs/10_robustness.md`. 아래 규칙은 결과를 보기 전에 커밋했다 (cfd710b).

## 규칙
- 학습: 선별 150·무작위 150·전체 270 x 시드 4, 5 (모델 6개)
- 판정 (시드 1~5): 짝지은 비교의 신뢰구간(기존 계산)이 0보다 위이고, **시드 5개 중 4개 이상에서 선별이 높으면** "차이 있음". 동점은 높은 것으로 세지 않는다
- 하락 기준: 시드+위치 부트스트랩 신뢰구간 위쪽 끝 ≤ 5%p이면 충족
- 시드+위치 신뢰구간도 함께 보고한다

## 실행
Kaggle API 실행 `qkdsy482/curation-seeds45`, 노트북 `kaggle/05_seeds45.ipynb` (`kaggle/build_extra_notebooks.py`로 생성). 본 실험 계획(지문 c15466d53a01cedb)에서 학습 시드만 4·5로 바꿨다. 10/11에 만든 본 실험의 `plan_b64.txt`는 데이터 이름·다운로드 경로가 없는 옛 형식이라, 같은 `plan.json`에서 압축 문자열을 다시 만들었다 (지문·묶음·설정은 같음). 평가는 200 epoch 30회 + 400 epoch 100회.

## 결과

- 추가 분석 규칙으로 **선별이 무작위보다 높다는 것을 확인**했다. 새 시드 2개에서 모두 선별이 높았고(+36, +23), 학습 시드 흔들림까지 넣은 신뢰구간도 0보다 위다. 기존 주 판정(시드 3개, 구분 불가)은 바꾸지 않는다
- 150개의 하락 기준은 시드 5개로도 확정하지 못했다. 전체 270의 시드 5가 30/100으로 낮아 흔들림이 커졌다(같은 데이터로 91~30). 결과를 빼지 않는다. 하락 기준은 135개 실험(B)으로 확인한 것으로 보고한다
- 학습 속도(200 epoch, 30회): 시드 4 선별 29 / 무작위 19, 시드 5 선별 26 / 무작위 1. 시드 1~3과 같은 방향으로 선별이 크게 앞선다


## 화면·채팅 표시 (10/13)
- `python -m curation_tools.train_eval --save-paired-seeds results/can_mh_c15466d53a01cedb_paired_5seeds.json`로 저장했다. 저장할 때 시드+위치 신뢰구간(1만 번, 난수 20261013)을 한 번 계산해 파일에 넣고(`robust`), 결과 조회(collect)는 읽기만 한다 (매번 계산하면 10초쯤 걸림)

- 채팅 결과 표, 데모 보고, 실험 결과 페이지(Can 150 탭)에 주 판정과 함께 표시한다
