# 예산 135개 실험 (B, 2026-10-13)

1주차 성공 기준 중 "학습 후보의 50% 이하 시범으로 전체 데이터 대비 성공률 하락 5%p 이내"를 확인했다. 지금까지의 150개는 270개의 56%라 이 조건에 맞지 않아, 정확히 50%인 135개로 다시 선별하고 학습했다.

## 설계 (결과 보기 전에 정함)
- 선별: 본 실험과 같은 분석(R-20261011-analyze01)에서 예산만 135개로 (`R-20261012-select-b135`, 학습 계획 지문 `4dfbbc02df2158ae`)
- 묶음: 선별 135 (19,093 프레임, 전체의 34%), 무작위 135 (27,873 프레임) x 시드 1, 2, 3. 조건별 균등·프레임 맞춘 무작위는 학습하지 않음
- 전체 270: 다시 학습하지 않고 Can 최종 평가(A)의 같은 모델을 쓴다. 학습 설정, 데이터 파일, 270개 구성, 평가 위치·행동 난수가 같아서 같은 시험 위치끼리 짝지을 수 있다
- 평가: 200 epoch 30회 + 400 epoch 100회, 위치와 행동 난수를 시험마다 12345+i로 고정
- 판정: 같은 위치끼리 짝지은 비교. "차이 있음"은 신뢰구간이 0을 넘고 세 시드 모두 같은 방향일 때만. 하락 기준은 신뢰구간 위쪽 끝(전체가 더 높은 쪽)이 5%p 이하이면 충족 (`train_eval.compare`의 `confirmed`와 같은 규칙, 짝지은 비교에도 넣음)
- 노트북 `kaggle/04_budget.ipynb` (Kaggle T4), 묶음당 학습 약 9분 + 평가 약 16분

## 해석
- **1주차 "절반 이하로 줄여도 하락 5%p 이내"는 충족했다.** 신뢰구간의 가장 나쁜 쪽에서도 선별 135가 전체 270보다 6.9%p 높다. 데이터 50%(프레임 34%)로 전체와 같거나 높은 성공률이다
- 선별 - 무작위는 +5.3%p로 1주차 목표치를 넘지만, 시드 3에서 무작위가 2개 더 많아(79 대 81) "차이 있음"은 아니다. Can 150과 같은 결론이다
- 학습 속도(200 epoch)에서는 선별이 세 시드 모두 앞섰다 (+32.2%p). Can 150(+38%p)과 같은 경향이다
- **135개가 150개보다 성공률이 높게 나온 것은 결론으로 쓰지 않는다.** 학습 설정은 같다(확인함). 무작위 135는 무작위 150보다 미숙 시범이 조금 적게 뽑혔고(33% 대 37%), 나머지는 학습 흔들림으로 본다. A에서도 같은 데이터가 시드에 따라 91, 68, 65로 흔들렸다. 서로 다른 실험끼리의 비교에는 이 흔들림과 묶음 뽑기 운이 섞이므로, 판정은 같은 실험 안에서 같은 시드·위치끼리만 한다
- 전체 270 - 선별 135의 크기(-13%p)도 이 흔들림이 섞인 값이라, 발표에서는 "하락 없음"이라는 방향만 말한다
